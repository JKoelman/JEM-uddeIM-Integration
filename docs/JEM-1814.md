# JEM #1814 — uddeIM organiser contact integration

## Goal

Allow a JEM event page to open uddeIM compose for the event organiser without putting JEM-specific behaviour into uddeIM core.

## Verified compose contract

The shared Joomla 6 compatibility/integration work verified this pattern:

```php
$url = Route::_(
    'index.php?option=com_uddeim'
    . '&task=new'
    . '&recip=' . (int) $this->item->created_by
    . '&nouserlist=7'
    . '&pm=' . rawurlencode($message),
    false
);

$url = htmlspecialchars($url, ENT_QUOTES, 'UTF-8');
```

This allows JEM to pass the organiser user ID and a prefilled message to uddeIM compose while leaving the actual message handling to uddeIM.

## Repository boundary

The JEM-facing glue belongs in this repository. Generic fixes required by `task=new`, recipient resolution, hooks or compose handling belong in `JKoelman/uddeIM` under the Joomla 6 compatibility/generic core track.

## Future work

- package the integration as a Joomla plugin/module or other independently installable extension;
- avoid hardcoding routes or assumptions that can be obtained through public APIs;
- add repository-owned Playwright coverage;
- document behaviour when organiser is missing, blocked, deleted or not allowed as a recipient;
- keep event/attendee recipient rules separate from generic uddeIM recipient visibility rules.
